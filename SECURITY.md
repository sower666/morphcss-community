# Security Policy

## Supported versions

MorphCSS Community is currently in pre-release and no supported software version has been published from this repository.

When releases begin, this section will identify the versions receiving security updates.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Report security concerns privately by email to [hello@morphcss.site](mailto:hello@morphcss.site). If GitHub private vulnerability reporting is enabled for this repository, you may use it instead.

Please include:

- the affected URL, file, release, and version, if known;
- clear reproduction steps or a minimal proof of concept;
- the expected impact and realistic attack scenario;
- relevant browser, runtime, or deployment details; and
- whether the issue has been disclosed elsewhere.

Please allow reasonable time for investigation and coordinated remediation before public disclosure. Reports are handled on a best-effort basis; no response or remediation time is guaranteed.
