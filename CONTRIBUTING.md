# Contributing to MorphCSS Community

Thank you for helping improve the MorphCSS Community project.

## Current scope

Until a software contribution policy is published, contributions are limited to:

- documentation corrections;
- broken-link or repository-metadata fixes;
- clear, well-scoped proposals for the future Community distribution; and
- reproducible feedback about public examples or documentation.

Do not submit MorphCSS product code, private implementation details, reverse-engineered source, licensed third-party code, or material you are not authorized to publish.

## Before opening a pull request

1. Search existing issues and pull requests.
2. Open an issue first for a substantial change or new policy proposal.
3. Keep the change focused and explain why it is needed.
4. Verify every changed link and avoid adding secrets, personal data, or private project information.
5. Confirm that you own the contribution or have the right to submit it.

By submitting a contribution, you grant the project owner a perpetual, worldwide, non-exclusive, royalty-free right to use, reproduce, modify, publish, and distribute that contribution as part of MorphCSS documentation and repository materials. You retain ownership of your original contribution.

Security reports must follow [SECURITY.md](SECURITY.md), not the public issue tracker. All participation must follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
