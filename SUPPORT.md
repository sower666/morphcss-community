# Support

MorphCSS Community is currently in pre-release. No downloadable Community software is available from this repository yet.

## Documentation

- [MorphCSS website](https://morphcss.site/)
- [Documentation](https://morphcss.site/docs/)

- [Community page](https://morphcss.site/community/)

## Repository questions

Use GitHub Issues for questions and feedback about the public documentation, repository structure, or future Community distribution. Search existing issues before opening a new one and include enough context to reproduce or evaluate the request.

Do not use public issues for suspected security vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Service level

Community support is provided on a best-effort basis. No response time, resolution time, maintenance period, or compatibility commitment is guaranteed. Private or commercial support is not included with the Community license.
