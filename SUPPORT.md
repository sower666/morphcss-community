# MorphCSS Community support

The CSS-only alpha [v0.1.0-alpha.0](https://github.com/sower666/morphcss-community/releases/tag/v0.1.0-alpha.0) is published. The proprietary-licensed edition is a pre-release, not MorphCSS Full.

## Start here

- [Quick start](docs/quickstart.md): download, integrity verification and installation.
- [Component reference](docs/components.md): published selectors and examples.
- [Theming guide](docs/theming.md): theme tokens and CSS-only dark mode.
- [Standalone starter](examples/community-starter/index.html): place the official CSS next to this HTML before serving.
- [Official website](https://morphcss.site/).

## Report a problem

Use the [public issue forms](https://github.com/sower666/morphcss-community/issues/new/choose) for reproducible alpha bugs, documentation corrections and future proposals. Include the exact release, browser/OS, viewport and steps. Never post secrets, private product source or security vulnerabilities. For security concerns follow [SECURITY.md](SECURITY.md).

## Service level

Best effort only. No response time, maintenance period, resolution deadline or compatibility commitment is guaranteed. Commercial support is not included in the Community license.
