# CSS component reference — v0.1.0-alpha.0

These are **selectors shipped in the published Community ZIP**, not a catalog of MorphCSS Full features. Community is CSS-only; it does not ship a runtime or behavior controllers.

## Layout

| Class | Behavior | Custom properties |
| --- | --- | --- |
| `.m-stack` | Vertical flex stack | `--m-stack-gap` |
| `.m-flex` | Generic flex container | `--m-flex-direction`, `--m-flex-wrap`, `--m-flex-gap`, `--m-flex-justify`, `--m-flex-align` |
| `.m-cluster` | Wrapping flex row | `--m-cluster-gap`, `--m-cluster-justify`, `--m-cluster-align` |
| `.m-grid` | Responsive auto-fit grid | `--m-grid-min`, `--m-grid-gap`, `--m-grid-columns` |
| `.m-grid-item` | Grid child placement | `--m-grid-column`, `--m-grid-row` |
| `.m-center` | Centered max-width region | `--m-center-max`, `--m-center-gutter` |

```html
<div class="m-grid" style="--m-grid-min: 16rem; --m-grid-gap: 1.25rem">
  <section class="m-surface-raised m-pad m-rounded">First</section>
  <section class="m-surface-raised m-pad m-rounded">Second</section>
</div>
```

The default `.m-grid` columns are generated by `repeat(auto-fit, minmax(min(100%, var(--m-grid-min, 16rem)), 1fr))`; the layout adapts to container width.

## Buttons and links

The `.m-button` class supports `data-m-intent="primary"` and `"neutral"`. Use a native `disabled` attribute for disabled buttons. An `<a class="m-button">` remains a link.

```html
<div class="m-cluster">
  <button class="m-button" data-m-intent="primary" type="button">Continue</button>
  <a class="m-button" data-m-intent="neutral" href="#more">Details</a>
  <button class="m-button" data-m-intent="neutral" disabled>Disabled</button>
</div>
```

`.m-link` supports default, `data-m-intent="quiet"` and `"plain"` styles. Supply a real `href` for navigational links.

## Badges

`.m-badge` supports `data-m-intent="primary"`, `"success"`, `"danger"` and the neutral default. Badges are visual only; include descriptive text.

```html
<span class="m-badge" data-m-intent="success">Available</span>
<span class="m-badge" data-m-intent="danger">Unavailable</span>
```

## Cards

Use `.m-card` with `.m-card__frame`. Optional elements include `.m-card__media`, `.m-card__body`, `.m-card__title`, `.m-card__summary`, `.m-card__meta` and `.m-card__actions`.

```html
<article class="m-card">
  <div class="m-card__frame">
    <div class="m-card__body m-stack">
      <h2 class="m-card__title">Card heading</h2>
      <p class="m-card__summary">A complete stacked card.</p>
    </div>
    <div class="m-card__actions">
      <a class="m-link" href="#details">Read details</a>
    </div>
  </div>
</article>
```

**CSS-only boundary:** a card has a safe stacked default. The stylesheet contains native container-query fallbacks for `data-m-adaptive` with `data-m-representation="auto"` and/or `data-m-layout="auto"`. It does **not** provide MorphCSS Full's semantic runtime or automatically populate `data-m-resolved-*` states.

## Utilities and limits

Published utility examples: `.m-pad`, `.m-margin`, `.m-surface-raised`, `.m-border`, `.m-rounded`, `.m-shadow`, `.m-text-center`, `.m-text-justify`, `.m-clamp-2`, `.m-truncate`.

Not bundled: a JavaScript controller, dynamic theme switcher, icons pack, modal/carousel behavior, navigation controller or commercial Full components. See the [starter demo](../examples/community-starter/index.html) and [theming guide](theming.md).
